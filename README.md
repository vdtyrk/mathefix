# Mathefix

Eine Lern-App für Mathe-Textaufgaben (Volksschule, ab der 3. Klasse):
180 Textaufgaben in 6 Gruppen, ausgewürfelte Rechenblätter, Vorlesefunktion,
Sterne und Abzeichen, Pflichtpausen und ein PIN-geschützter Elternbereich.

**➡️ App starten:** einfach die GitHub-Pages-Seite dieses Repositories öffnen.

- Läuft komplett im Browser (Tablet und PC), keine Anmeldung nötig.
- Der Fortschritt bleibt privat auf dem eigenen Gerät gespeichert.
- Keine Werbung, keine Datensammlung, keine externen Dienste.
- Tipp fürs Tablet: Seite öffnen → „Zum Startbildschirm hinzufügen“ –
  danach funktioniert die App wie eine installierte App, auch offline.

Die Aufgaben liegen als bearbeitbare JSON-Dateien im Ordner `data/`.
